## What's new in 0.2.1

### Easier to use

- **The ribbon stays open when you click its tab.** Clicking the tab you are already on no longer hides the ribbon. To collapse it, double-click a tab or use the arrow at the right end of the ribbon, as in Office.
- **PDF Tools: progress and Cancel.** Long jobs such as text recognition or compressing many files show a progress bar, the file and page being worked on, the time so far and a **Cancel** button. Files already finished are kept and nothing is left half-written. A job keeps running when you switch to Recent or Starred, and the PDF Tools item in the sidebar shows when it is working or done.
- **The PDF editor asks before it saves into your file.** Page tools (insert, delete, rotate pages and so on) used to save your unsaved notes into the original without asking. They now ask first, once per file. The editor also warns before a save would break a digital signature.
- **Faster, smoother PDF viewing.** Large PDFs open faster, and Ctrl+wheel zoom and scrolling through long documents are smoother.
- **Docs** shows the font a document is really displayed in (Calibri) when the document does not name one.

### Accessibility

- **Easier-to-read text.** Grey labels, file details and hints now meet the WCAG AA contrast level. Dark mode has two distinct grey levels again, and the File button and other filled buttons use dark text in dark mode.
- **One clear keyboard focus outline**, in each app's colour, across the whole suite.
- **Switch documents from the keyboard.** Ctrl+Tab and Ctrl+Shift+Tab work from anywhere. On Home and the tab strip, Ctrl+1–9 and Ctrl+PageUp/PageDown work too, and the arrow keys, Enter and Delete work on the tabs. Inside an editor, Ctrl+1–9 keep their Office meanings.
- **Ribbons work with screen readers and arrow keys.** In Docs, PDF, Sheets and Slides the ribbon tabs are real tabs, and toggle buttons such as Bold, alignment and the drawing tools say whether they are on. PDF page thumbnails can be reached with the keyboard, and Ctrl+Y redoes.
- **Settings** keeps keyboard focus inside its window. The Move to folder picker and the AutoSave switch now work from the keyboard.
- **Windows Contrast themes** keep the focus outline, the selected tab, pressed buttons and switches visible.

### Privacy

- **No network use you did not ask for.** English spell-check dictionaries now come with the app instead of being downloaded each time it starts. The HTML editor's preview blocks pictures, fonts and scripts from the internet until you choose **Load web content**.
- **Settings > About** shows the license, the copyright and the third-party notices.

### Upgrading

From 0.2.0, open Settings > About, choose **Check now**, then **Download and install**. You can also download the installer below and run it.

The installer is still not code-signed, so Windows SmartScreen may warn the first time you run it.
